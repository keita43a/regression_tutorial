Chapter 19 ヘドニック法

19.1 ヘドニック法とは

19.1.1 環境の価値をどう測るか

第14章から第18章では、ある政策や出来事が結果に与えた因果効果をどう推定するかを学んできた。この章と次章では、少し違う問いを扱う。市場で売買されていないものの価値を、どうやって金額で測るかという問いである。

きれいな空気、静かな住環境、近所の公園、豊かな漁場。これらはどれも人々にとって価値があるが、値札はついていない。値札がないから価値がゼロだということにしてしまうと、環境を守るための政策の便益は常にゼロと評価されてしまい、費用便益分析が成り立たない。

そこで、市場価格を持たない財（非市場財）の価値を推定する手法が発達してきた。大きく2つの考え方がある。

  • 顕示選好法（revealed preference）：人々の実際の行動から価値を読み取る。環境の良し悪しが、住宅価格や旅行費用といった観察できる金額に反映されていることを利用する
  • 表明選好法（stated preference）：仮想的な状況を提示して「いくらまでなら払うか」を直接たずねる。市場での行動が存在しない場合にも使える

本章で扱うヘドニック法（hedonic method）は顕示選好法の代表である。次章の選択実験は表明選好法の代表となる。

19.1.2 ヘドニック価格関数

ヘドニック法の出発点は、住宅は属性の束であるという考え方である。

私たちが住宅を買うとき、「住宅」という単一の商品を買っているわけではない。部屋の広さ、駅からの距離、学区の質、周辺の治安、そして空気のきれいさ——こうした属性の組み合わせに対してお金を払っている。したがって住宅価格は、これらの属性の関数として書けるはずである。

\[ P_i = f(\text{構造属性}_i, \ \text{近隣属性}_i, \ \text{環境属性}_i) \]

この関数 \(f\) をヘドニック価格関数と呼ぶ。構造属性は部屋数や築年数、近隣属性は学区や犯罪率、環境属性は大気汚染や騒音といったものである。

この考え方に立つと、環境属性で価格を微分したものが、環境の価値になる。

\[ \frac{\partial P}{\partial (\text{環境属性})} = \text{環境属性1単位あたりの限界支払意思額} \]

これを限界支払意思額（marginal willingness to pay, MWTP）と呼ぶ。アンケートで「いくら払いますか」と聞かなくても、実際の住宅市場の取引から環境の価値が読み取れる、というのがヘドニック法の魅力である。

とはいえ、この式だけを見せられてもピンとこないだろう。次節で具体例に落として考えてみよう。

19.1.3 同じような部屋なのに家賃が違う

ここまでの説明は抽象的だったので、具体的な例で考えてみよう。

あなたが引っ越し先を探していて、次の2つの賃貸マンションを見つけたとする。

A棟 B棟
最寄り駅からの徒歩 10分 10分
間取り 1LDK 1LDK
専有面積 40㎡ 40㎡
築年数 10年 10年
階数 3階 3階
家賃（月額） 12.5万円 11.0万円

不動産情報サイトに載っている条件は、どれを見ても同じである。それなのに家賃は月1.5万円、年間にすると18万円も違う。なぜだろうか。

現地に行ってみると理由がわかった。A棟の窓の外は公園で、緑が見えて静かだった。一方のB棟は幹線道路に面していて、窓を開けると車の音がうるさく、排気ガスのにおいもする。

ここで大事なのは、この1.5万円の差を生んでいる「静かさ」や「空気のきれいさ」には、値札がついていないということである。不動産屋は「公園ビュー料金 1.5万円」という項目を請求書に書いたりはしない。それでも、借り手たちが「うるさくて空気の悪い部屋は、その分安くないと借りない」と判断した結果として、家賃の差という形で価値が現れている。

この価格差こそが、人々が環境に支払っている金額である。これがヘドニック法の核心にあるアイデアだ。直接測れないもの（静かさ、空気のきれいさ、緑の眺め）の価値を、直接測れるもの（家賃）の差として読み取るのである。

19.1.4 なぜ引き算では足りないのか

では、A棟とB棟の家賃を引き算すれば環境の価値がわかるのだろうか。残念ながら、そう簡単ではない。

現実に2つの物件を比べると、パンフレットに載っていない違いがいくらでも出てくる。日当たり、部屋の設備の新しさ、管理の行き届き方、周辺の治安、スーパーまでの距離。これらのどれかがA棟の方が良ければ、1.5万円の差は「環境の価値」だけでなく「日当たりの価値」や「設備の価値」も含んでしまう。

たった2軒を比べる限り、この問題は解けない。そこで、たくさんの物件のデータを集めて、観察できる属性をすべてコントロールした上で、環境属性の効果だけを取り出すという方法をとる。

これはまさに第14章までに学んできた重回帰そのものである。

\[ \text{家賃}_i = \beta_0 + \beta_1 \cdot \text{環境属性}_i + \gamma_1 \cdot \text{面積}_i + \gamma_2 \cdot \text{築年数}_i + \cdots + \varepsilon_i \]

重回帰の係数 \(\beta_1\) は「他の変数を一定に保ったときの効果」を表す。つまり \(\beta_1\) は、面積も築年数も駅からの距離もまったく同じ物件どうしを比べたときに、環境属性の違いが家賃をいくら動かすかを意味する。先ほど「A棟とB棟の条件が完全に同じだったら」と考えた思考実験を、データの力で近似的に実現しているのである。

ヘドニック法に特別な推定手法が必要ないのはこのためだ。難しいのは推定ではなく、どの属性をコントロール変数に入れるべきかを考えることにある。入れ忘れた属性があると、その効果が環境属性の係数に紛れ込んでしまう。演習ではまさにこの現象を目にすることになる。

19.1.5 対数線形モデルと係数の解釈

実際の推定では、価格と環境属性の両方を対数変換した対数線形モデル（log-log モデル）がよく使われる。

\[ \log(P_i) = \beta_0 + \beta_1 \log(\text{環境属性}_i) + \gamma' \mathbf{x}_i + \varepsilon_i \]

両辺が対数なので、\(\beta_1\) は弾力性として解釈できる。すなわち「環境属性が1%変化したときに住宅価格が何%変化するか」を表す。

\[ \beta_1 = \frac{\partial \log P}{\partial \log(\text{環境属性})} = \frac{\% \ \text{の価格変化}}{\% \ \text{の環境属性の変化}} \]

弾力性は単位に依存しないので解釈しやすいが、政策評価では「1単位の改善が何円の価値を持つか」という金額表示が必要になることも多い。対数線形モデルの推定値から限界価値を求めるには、次のように変換する。

\[ \frac{\partial P}{\partial (\text{環境属性})} = \beta_1 \times \frac{\bar{P}}{\overline{\text{環境属性}}} \]

ここで \(\bar{P}\) と \(\overline{\text{環境属性}}\) はそれぞれの平均値である。この計算は演習で実際に行う。

19.2.5 変数を加える

第14章で学んだ欠落変数バイアスを思い出そう。大気汚染がひどい地域は、工業地帯や幹線道路の近くであることが多い。そうした地域は住宅そのものが小さかったり、治安が悪かったりする。つまり以下のような構造がある。

\[ \text{工業地帯に近い} \rightarrow \begin{cases} \text{大気汚染（悪）} \\ \text{住宅の質・治安（悪）} \end{cases} \]

19.2.7 限界価値の計算

弾力性を金額に換算してみよう。先ほどの変換式を使う。

b_nox <- coef(reg_full)["lnox"]
mean_price <- mean(hprice2$price)
mean_nox <- mean(hprice2$nox)

# NOx 1 pphm あたりの限界価値
mwtp_nox <- b_nox * mean_price / mean_nox
mwtp_nox
##      lnox 
## -2505.624

平均的な住宅（価格22,512ドル、NOx濃度5.55 pphm）において、窒素酸化物濃度を1 pphm 削減することは約2,500ドルの価値を持つという推定になる。平均価格の1割強にあたる金額であり、大気の質が住宅価値のかなりの部分を説明していることがわかる。

この数字があれば、大気汚染対策の便益を金額で表現できる。たとえばある地域の住宅が10,000戸あり、政策によってNOx濃度が1 pphm 改善するなら、便益はおよそ2,500ドル × 10,000戸 = 2,500万ドルと見積もれる。費用便益分析ではこのように使われる。

19.3 ヘドニック法の注意点

ヘドニック法は実際の市場取引を使うため説得力があるが、いくつか注意すべき点がある。

内生性の問題

大気汚染の水準はランダムに割り当てられたものではない。工場は地価の安い場所に立地するかもしれず、その場合は「汚染が価格を下げた」のか「地価が安いから工場が来た」のかを区別できない。これは第18章で学んだ逆の因果関係の問題である。厳密な研究では、風向きや地形など汚染に影響するが住宅価格には直接影響しない変数を操作変数として用いる。

空間的自己相関

近くにある住宅どうしは、観察できない要因（街並みの雰囲気など）を共有している。この場合、誤差項が地域内で相関し、通常の標準誤差は過小になる。地域単位でクラスター標準誤差を使うか、空間計量経済学の手法を用いる必要がある。

測れるのは「市場に現れる価値」だけ

ヘドニック法が捉えるのは、住宅を買う人が認識し、価格に反映させた価値だけである。その地域に住んでいない人が感じる価値（たとえば「見たこともない森が守られていること自体に価値を感じる」といった存在価値）は原理的に捉えられない。

市場が機能していることが前提

人々が住宅の属性を正しく認識し、自由に住み替えられることが前提になっている。情報が不完全だったり、住み替えの費用が大きかったりすると、価格は属性の価値を正しく反映しない。

19.4 まとめ

ヘドニック法は、住宅価格という実際に観察できる金額から、値札のない環境の価値を読み取る手法である。推定の道具は第14章までに学んだ重回帰そのものであり、新しい推定手法は必要ない。難しいのは推定ではなく、どの変数をコントロールすべきかを考えることである。

一方で、ヘドニック法には限界もある。住宅市場という「代理の市場」が存在しなければ使えないのだ。まだ存在しない政策の価値や、市場で取引されない財の価値——たとえば「持続可能な方法で獲られた水産物」に消費者がいくら払うのか——は、この方法では測れない。

そうした場合に使うのが、次章で学ぶ選択実験である。
